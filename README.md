# AEROX Air Purifier Store

A modern and responsive e-commerce website for an air purifier brand, built with React and Tailwind CSS. The project features a premium futuristic UI with smooth GSAP animations and a complete shopping experience.

## ✨ Features

- 🏠 Modern responsive homepage
- 🛍️ Product and shop pages
- 🛒 Shopping cart with quantity management
- 🔐 Login & signup pages
- 🔔 React Hot Toast notifications
- ⚡ GSAP + ScrollTrigger animations
- 📱 Fully responsive design
- ❓ FAQ page
- 🚚 Shipping & Returns pages
- 🔒 Privacy & Cookies Policy
- 💰 Refund Policy
- 📞 Contact page
- 💡 Technology page
- 🎨 Premium dark/cyan futuristic UI

## 🛠️ Technologies

- React
- React Router
- Tailwind CSS
- GSAP
- ScrollTrigger
- React Hot Toast
- Remix Icon
